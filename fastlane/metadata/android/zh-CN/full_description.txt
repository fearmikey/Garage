Garage 是一款注重隐私的 Android 车辆管理应用。在一个地方记录您所有车辆的保养、加油与电动车充电、费用、改装、证件和行程。无广告、无追踪、无需注册账户，并且完全离线可用。

<b>车辆</b>
<ul>
<li>管理多辆车：轿车、卡车、摩托车、纯电动车和插电式混合动力车</li>
<li>用相机扫描 VIN 条形码并自动解码车辆规格（NHTSA vPIC）</li>
<li>可编辑的规格表，支持自定义字段</li>
<li>行驶证和保险信息，到期前自动提醒</li>
<li>保存配件信息、笔记和自定义证件，支持照片附件</li>
</ul>

<b>保养</b>
<ul>
<li>完整的保养历史时间线，可按类别和日期范围筛选</li>
<li>根据里程和时间间隔给出智能保养建议</li>
<li>内置保养计划模板，也可添加自定义规则</li>
<li>将保养历史导出为 PDF，卖车时非常实用</li>
</ul>

<b>加油与充电</b>
<ul>
<li>记录加油及燃油标号，自动计算油耗</li>
<li>记录电动车充电，统计充电速度和能效</li>
<li>油耗、价格和花费趋势图</li>
</ul>

<b>费用与分析</b>
<ul>
<li>汇总燃油、保养、改装和保险的总用车成本</li>
<li>每公里或每英里成本</li>
<li>仪表盘显示车队概览、近期动态和即将到期的保养</li>
</ul>

<b>更多工具</b>
<ul>
<li>记录改装和升级及其费用</li>
<li>知识库：扭矩规格、油液容量和参考笔记</li>
<li>行程记录（手动或 GPS），区分商务和个人里程</li>
<li>通过蓝牙或 Wi-Fi 进行 OBD-II 诊断：实时传感器数据、读取和清除故障码</li>
<li>安全召回查询（NHTSA，适用于美国车辆）</li>
<li>主屏幕小部件和快捷设置图块，快速记录加油和更新里程表</li>
</ul>

<b>您的数据，由您掌控</b>
<ul>
<li>所有数据都保存在您的设备本地</li>
<li>手动和自动备份与恢复</li>
<li>可选同步到您自己的 WebDAV 服务器（Nextcloud、ownCloud 等）</li>
<li>可选与自托管的 LubeLogger 实例双向同步</li>
<li>仅在 VIN 解码、召回查询以及您自行配置的服务器时使用网络</li>
</ul>

<b>个性化</b>
<ul>
<li>Material You 设计，提供多种主题配色以及浅色和深色模式</li>
<li>支持公制或英制单位，以及包括人民币在内的多种货币</li>
<li>支持简体中文、英语、德语、法语、西班牙语、意大利语、葡萄牙语、荷兰语、波兰语、俄语和土耳其语</li>
</ul>
