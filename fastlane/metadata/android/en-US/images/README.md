# F-Droid Fastlane Graphic Assets

Place your app store graphic assets in this directory for F-Droid and Fastlane:

- `icon.png`: High-resolution 512x512 PNG app icon
- `featureGraphic.png`: 1024x500 PNG banner graphic (optional)
- `phoneScreenshots/`: Save 16:9 or phone aspect ratio PNG screenshots here (e.g., `1.png`, `2.png`, `3.png`, `4.png`)
